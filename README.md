# CS361Project

# Curriculum Information & Graduation Verification System

## Project Definition

ระบบข้อมูลหลักสูตรและการตรวจสอบการสำเร็จการศึกษา เป็นระบบกลางที่ช่วยให้ผู้ใช้สามารถเข้าถึง ค้นหา และสอบถามข้อมูลที่เกี่ยวข้องกับหลักสูตร เช่น ข้อมูลหลักสูตร แผนการเรียน รายวิชา วิชาบังคับก่อน และเงื่อนไขการสำเร็จการศึกษา

ระบบจะพัฒนาอย่างต่อเนื่องตาม Requirements ของ V1–V7 โดยในแต่ละ Version จะเพิ่มความสามารถและปรับปรุง Architecture ให้เหมาะสมกับความต้องการของระบบ

## Project Vision

พัฒนาระบบที่รองรับกระบวนการด้านการศึกษาอย่างครบวงจร ตั้งแต่การเข้าถึงข้อมูล การค้นหา การตรวจสอบการสำเร็จการศึกษา ไปจนถึงการบริหารจัดการข้อมูลหลักสูตรอย่างเป็นระบบและปลอดภัย

## V1 – Information

V1 มุ่งเน้นให้บุคคลทั่วไปสามารถเข้าถึงข้อมูลหลักสูตรได้โดยไม่ต้องเข้าสู่ระบบ

### Primary User

บุคคลทั่วไปที่ต้องการดู ค้นหา และสอบถามข้อมูลที่เกี่ยวข้องกับหลักสูตร

### V1 Features

- ดูข้อมูลคณะ สาขา และหลักสูตร
- ค้นหาและกรองข้อมูลตามคณะและสาขา
- ดูรายละเอียดหลักสูตร
- ดูโครงสร้างหลักสูตรและแผนการเรียน
- ค้นหาและดูรายละเอียดรายวิชา
- ดูวิชาบังคับก่อนและความสัมพันธ์ระหว่างรายวิชา
- ดูเงื่อนไขการสำเร็จการศึกษา
- สอบถามข้อมูลที่เกี่ยวข้องกับหลักสูตร

## Boundary

### Inside the System

- ข้อมูลหลักสูตร
- ข้อมูลแผนการเรียน
- ข้อมูลรายวิชา
- รายละเอียดรายวิชา
- วิชาบังคับก่อน
- เงื่อนไขการสำเร็จการศึกษา
- การค้นหาและเรียกดูข้อมูล
- การสอบถามข้อมูลเกี่ยวกับหลักสูตร

### Outside the System

- การลงทะเบียนเรียน
- การจัดตารางเรียน
- การบริหารจัดการหลักสูตร
- การตรวจสอบการสำเร็จการศึกษาของนักศึกษาแต่ละบุคคล

### External Actor

- บุคคลทั่วไป

### External Systems / Data Sources

แหล่งข้อมูลภายนอกที่เกี่ยวข้องจะต้องได้รับการตรวจสอบและยืนยันก่อนนำมาใช้เป็นแหล่งข้อมูลของระบบ เช่น

- ระบบข้อมูลมหาวิทยาลัย
- ระบบหรือเว็บไซต์ TCAS
- เว็บไซต์หรือเอกสารหลักสูตรจากแหล่งข้อมูลทางการ

### Boundary Flows

**ผู้ใช้ → ระบบ**

- ค้นหาคณะ / สาขา / หลักสูตร
- กรองข้อมูลตามคณะและสาขา
- ดูรายละเอียดหลักสูตร
- ดูโครงสร้างและแผนการเรียน
- ค้นหาและดูรายละเอียดรายวิชา
- ดูวิชาบังคับก่อน
- ดูเงื่อนไขการสำเร็จการศึกษา
- สอบถามข้อมูลเกี่ยวกับหลักสูตร

**ระบบ → ผู้ใช้**

- แสดงผลการค้นหา
- แสดงรายละเอียดหลักสูตรและสาขา
- แสดงรายการและรายละเอียดรายวิชา
- แสดงวิชาบังคับก่อนและความสัมพันธ์ระหว่างรายวิชา
- แสดงเงื่อนไขการสำเร็จการศึกษา
- แสดงคำตอบหรือข้อมูลที่เกี่ยวข้องกับคำถาม

**External Systems / Data Sources → ระบบ**

- ข้อมูลหลักสูตรและรายวิชา
- ข้อมูลการเปลี่ยนแปลงหลักสูตร
- ข้อมูลจากแหล่งข้อมูลต้นทางที่เกี่ยวข้อง

> รูปแบบการรับหรือแลกเปลี่ยนข้อมูล และ Source of Truth จะได้รับการตรวจสอบและกำหนดให้ชัดเจนตามผลการ Validate และ Project Grill
